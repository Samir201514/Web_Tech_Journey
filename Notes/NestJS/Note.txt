NestJS is a Node Framework which runs on NodeJS and build on top of ExpressJS for building efficient, scalable backends, from one file to enterprise-grade systems.building efficent and scealable server-side applications. Built with TypeScript and inspired by AngularJS. Use Modular Architeacture. Similar to ASP.NET, SpringBoots
